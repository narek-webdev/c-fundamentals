# 🏗️ Structs in C

> C programs that demonstrate how to use `struct` to group related data and perform operations on it.

---

## 📂 Problems

| # | File | Problem | Concepts |
|---|------|---------|----------|
| 1 | [rectangle_area.c](./rectangle_area.c) | 🟦 Calculate the area of a rectangle | `struct`, `scanf`, arithmetic |
| 2 | [point_operations.c](./point_operations.c) | 📍 Compute sum and product of a point's coordinates | `struct`, `scanf`, arithmetic |
| 3 | [circle_calculations.c](./circle_calculations.c) | 🔵 Calculate circumference and area of a circle | `struct`, `double`, `scanf` |

---

## 🧠 Concepts Covered

- ✅ Defining and using `struct` types
- ✅ Storing related fields (`int`, `double`) in a single structure
- ✅ Reading struct field values from user input with `scanf`
- ✅ Performing arithmetic operations on struct fields
