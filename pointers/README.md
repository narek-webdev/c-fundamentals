# 👉 Pointers in C

> C programs that explore pointers — memory addresses, dereferencing, pointer arithmetic, and low-level system behavior.

---

## 📂 Problems

| # | File | Problem | Concepts |
|---|------|---------|----------|
| 1 | [pointer_addresses.c](./pointer_addresses.c) | 🗂️ Declare three pointers of different types and print their addresses | pointer declaration, `%p`, address-of `&` |
| 2 | [pointer_dereference.c](./pointer_dereference.c) | 🔓 Print a variable's value through a pointer | dereferencing `*`, `&` |
| 3 | [pointer_arithmetic.c](./pointer_arithmetic.c) | ➕ Perform addition and subtraction using pointers | pointer arithmetic, `*`, `&` |
| 4 | [endianness_check.c](./endianness_check.c) | 🖥️ Check if the system is little-endian or big-endian | `char*` pointer, memory layout |

---

## 🧠 Concepts Covered

- ✅ Declaring and initializing pointers (`int*`, `float*`, `char*`)
- ✅ Address-of operator (`&`) and dereference operator (`*`)
- ✅ Printing memory addresses with `%p`
- ✅ Arithmetic operations through pointers
- ✅ Low-level memory inspection (endianness)
