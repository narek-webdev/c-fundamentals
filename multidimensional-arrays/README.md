# 🔢 Multidimensional Arrays in C

> C programs that work with 2D arrays and matrices — filling, transforming, and rotating.

---

## 📂 Problems

| # | File | Problem | Concepts |
|---|------|---------|----------|
| 1 | [snake_matrix.c](./snake_matrix.c) | 🐍 Build and print an n×n snake (zigzag) matrix | 2D arrays, nested loops, column-wise fill |
| 2 | [matrix_transpose.c](./matrix_transpose.c) | 🔀 Transpose a square matrix along the main diagonal | 2D arrays, functions, symmetric swap |
| 3 | [matrix_rotate_180.c](./matrix_rotate_180.c) | 🔄 Rotate a square matrix by 180 degrees | 2D arrays, index manipulation |

## 🧠 Concepts Covered

- ✅ Declaring and initializing 2D arrays
- ✅ Nested loops for matrix traversal
- ✅ Column-wise and row-wise iteration
- ✅ In-place matrix transformations (transpose, rotation)
- ✅ Passing 2D arrays to functions
